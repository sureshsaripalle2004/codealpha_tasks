# Task 1 – Credit Scoring Model

Machine learning-based credit scoring model developed as part of the CodeAlpha Machine Learning Internship.

## Project Overview

This project develops and evaluates machine learning models for credit risk classification using the UCI Statlog German Credit dataset.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Models

- Logistic Regression
- Decision Tree
- Random Forest

## Best Model

Logistic Regression was selected based on the overall evaluation of recall, F1-score, and ROC-AUC.
